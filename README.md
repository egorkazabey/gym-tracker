# Gym Tracker — Telegram Mini App

Трекер силовых тренировок внутри Telegram: недельная программа, запись подходов (вес × повторения), статистика и графики прогресса. Тёмный дизайн.

**Полностью бесплатно:** нет сервера и базы данных. Фронтенд — статический сайт на Vercel, данные каждого пользователя хранятся в его **Telegram CloudStorage** (привязаны к паре «пользователь + бот», синхронизируются между устройствами).

## Локальный запуск

```bash
npm install
npm run dev      # http://localhost:5173 — вне Telegram данные пишутся в localStorage
npm test         # unit-тесты статистики и формата хранения
npm run build    # сборка в dist/
```

## Деплой на Vercel (бесплатно)

1. Залей папку в репозиторий на GitHub.
2. На [vercel.com](https://vercel.com) → **Add New → Project** → выбери репозиторий. Vercel сам определит Vite (Build: `npm run build`, Output: `dist`). Нажми **Deploy**.
3. Получишь адрес вида `https://gym-bot-xxx.vercel.app`. Дальше каждый `git push` обновляет приложение автоматически.

## Создание бота (без кода)

1. В Telegram открой **@BotFather** → `/newbot` → придумай имя и username.
2. `/mybots` → твой бот → **Bot Settings → Configure Mini App → Enable Mini App** → вставь URL с Vercel. Это откроет мини-аппу по ссылке `t.me/<бот>?startapp` и кнопкой «Open» в профиле бота.
3. Там же **Bot Settings → Menu Button** → укажи тот же URL и текст, например «🏋️ Тренировки» — кнопка появится слева от поля ввода в чате с ботом.

Готово: открывай бота, жми кнопку меню. Каждый пользователь видит только свои программы и тренировки.

## Как устроено хранение

Telegram CloudStorage: до 1024 ключей на пользователя, значение до 4096 символов, ключи только `A-Z a-z 0-9 _ -`.

| Ключ | Содержимое |
|---|---|
| `p_n`, `p_0…` | Программа (дни + упражнения), JSON, при необходимости разбит на куски по 4000 символов |
| `s_YYYYMMDD_<dayId>` | Одна тренировка: `{"x":{"e1":[[80,8],[77.5,7]]},"f":1}` |

Одна тренировка = один ключ → хватит примерно на 1000 тренировок (5+ лет при 4 в неделю). На экране «Программа» есть индикатор заполненности и резервная копия (экспорт в буфер обмена / импорт).

## Структура

- `src/tg.ts` — обёртка Telegram WebApp + CloudStorage (с фолбэком на localStorage)
- `src/store.ts` — состояние, загрузка, автосохранение с debounce
- `src/model.ts`, `src/stats.ts` — типы, формат хранения, расчёт рекордов/1ПМ/объёма
- `src/pages/` — Сегодня, Тренировка, Статистика, История, Программа

## Ограничения

- Напоминаний от бота нет — для них нужен постоянно работающий сервер.
- Удалённые из программы упражнения скрываются, но их статистика сохраняется.
